# 電車買幫手

以繁體中文呈現的電動車選購 AI 助手介面原型。這是純前端靜態頁面，沒有串接 AI、送出問題或其他後端功能。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。

## 部署到 GitHub 與 Vercel

1. 在 GitHub 建立一個空白 repository。
2. 將這個資料夾的檔案推送到 repository。
3. 在 Vercel 選擇 **Add New → Project**，匯入該 GitHub repository。
4. Framework Preset 選 **Other**；Build Command 與 Output Directory 留空，然後部署。

之後每次推送變更到 GitHub，Vercel 都會自動重新部署。
